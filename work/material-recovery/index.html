Contactless Material Assessment

When a building comes down, almost everything in it gets thrown away — partly because nobody can tell, cheaply and without destroying it, which material is still good. This combines thermal imaging, RGB and depth sensing with machine learning to judge in-situ material condition without touching it, so the parts worth recovering can be identified before demolition rather than after.

The problem

Reuse decisions in deconstruction are usually made by eye, or not at all. Anything uncertain gets landfilled, because the cost of finding out — cutting into the assembly, taking samples, sending them away — exceeds the value of the material. The economics only change if the assessment is fast, cheap, and leaves the building intact.

Approach

No single sensor answers the question, so the approach fuses several: thermal for what's behind the surface, RGB for what's on it, depth for geometry. Machine learning turns that stack into a condition judgement. The case study ran on drywall deconstruction — the highest-volume, most routinely-landfilled material in a building interior.

Result

The case study showed the sensing stack can guide a deconstruction process in practice, with the cost and embodied-carbon savings that follow from recovering material instead of replacing it.
